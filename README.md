# Inkoly Quiz

Онлайн-платформа для домашніх квізів: ведучий керує грою з планшета, питання
і лідерборд ідуть на телевізор, гості грають зі своїх телефонів.

Специфікація: PRD «Онлайн-платформа для домашніх квізів» v2.2 — очікується
в `docs/PRD.md`, у репозиторії його поки немає.
Правила розробки: [`CLAUDE.md`](./CLAUDE.md).

## Стек

| Шар         | Технологія                                               |
| ----------- | -------------------------------------------------------- |
| Фреймворк   | Nuxt 4 (Vue 3, TypeScript strict), статичний SPA без SSR |
| Стан        | Pinia                                                    |
| Бекенд і БД | Supabase — PostgreSQL, Auth, Storage, Realtime           |
| Стилі       | SCSS + CSS-змінні для тем                                |
| Локалізація | `@nuxtjs/i18n`, англійська; інфраструктура під uk/pl     |
| Хостинг     | Cloudflare Pages (статика), Supabase у Франкфурті        |

## Запуск

Потрібні Node **22.12+** і Docker для локальної Supabase. На Node 20 тулінг
не працює: ESLint-конфіг Nuxt використовує `Object.groupBy` (Node 21+),
а commitlint 21 вимагає 22.12.

```bash
nvm use              # бере версію з .nvmrc
npm install
cp .env.example .env # значення видасть `npm run db:start`
npm run db:start     # локальна Supabase в Docker
npm run dev
```

## Поверхні

| Маршрут                         | Пристрій                                     |
| ------------------------------- | -------------------------------------------- |
| `/dashboard`, `/editor/:quizId` | ведучий, підготовка квізу                    |
| `/host/:roomId`                 | пульт ведучого — планшет                     |
| `/screen/:joinToken`            | загальний екран — телевізор, без авторизації |
| `/join`, `/play/:joinToken`     | учасник — телефон                            |
| `/admin`                        | заброньовано під фазу 2, гард за роллю       |

## Стан

Каркас фази 1: структура, дизайн-токени, локалізація, стори, маршрути, тулінг.
Схеми бази, серверних функцій і ігрового циклу ще немає — див.
[`docs/contract.md`](./docs/contract.md), там же три рішення, які треба ухвалити
до першої міграції.

## Збірка і деплой

```bash
npm run generate     # статика в .output/public
```

Cloudflare Pages: команда білду `npm run generate`, каталог виходу
**`.output/public`** (не `dist`). Змінні оточення білду — `SUPABASE_URL`
і `SUPABASE_KEY`: при статичній збірці вони вшиваються в бандл, тож зміна
ключа вимагає передеплою.

SPA-fallback уже на місці — `200.html` і `404.html` генеруються автоматично,
тож прямий вхід на `/play/:token` після сканування QR працює.
